从2021年宣布造车开始：小米要做的不只是"一台电动车"，而是"一台让用户心动的Dream Car"
- 两年深度打磨，投入百亿研发，首款车直接对标C级豪华纯电轿车市场
- 雷军亲自带队，用做消费电子的极致效率做汽车——"人车家全生态"首次真正落地到四轮设备
- 目标：把顶级性能、智能体验和合理价格结合，重新定义20-30万级纯电轿车标杆

## 产品定位

### 核心判断：好看、好开、舒适、安全——新一代驾驶者之车

### 车型矩阵：三款配置覆盖不同需求
- **SU7 标准版**：21.59万起，后驱长续航，CLTC 700km+，面向日常通勤
- **SU7 Pro版**：24.59万起，后驱超长续航，CLTC 830km+，面向长途出行
- **SU7 Max版**：29.99万起，双电机四驱，零百2.78秒，面向性能玩家

### 核心要求：设计、性能、智能、安全四大维度全面进阶
- 经验匹配：小米十年消费电子研发积累 + 汽车工业顶级供应链 + 人车家生态协同

## 核心产品力

### 外观设计：风阻系数0.195，量产车最低
- 低趴轿跑姿态，车长4997mm、轴距3000mm、车宽1963mm，C级豪华轿车比例
- 水滴大灯、流线溜背、隐藏式门把手，9种车身颜色可选
- 光环尾灯内置360颗超红光LED，点亮辨识度极高

### 性能驾控：超电机+高压平台
- V6s超级电机，最高转速21000rpm，Max版双电机总功率495kW
- 零百加速2.78秒（Max版），最高车速265km/h
- 全系全域碳化硅高压平台，800V高压架构，充电效率行业领先

### 续航补能：最长800km+，充电15分钟补能220km

- 标准版73.6kWh比亚迪磷酸铁锂电池，Pro/Max版宁德时代三元锂电池
- CLTC续航：标准版700km / Pro版830km / Max版800km
- 快充10%-80%最快15分钟，补能效率对标顶级800V平台

### 智能座舱：五屏联动的人车家生态
- 16.1英寸3K中控屏 + 7.1英寸翻转仪表屏 + 56英寸HUD抬头显示
- 第三代骁龙8座舱芯片，AI算力30TOPS，五屏可联动
- Xiaomi HyperOS人车家全生态：手机、平板、智能家居无缝流转

### 智能驾驶：全栈自研，硬件拉满
- Max版配备1颗激光雷达 + 11个高清摄像头 + 3个毫米波雷达 + 12个超声波雷达
- 英伟达Orin芯片，算力508TOPS
- 支持城市NOA、高速NOA、代客泊车等高阶辅助驾驶功能

![贴图](assets/v2-45e0a12bd5830821cd12caea2e01518c_1440w.jpg){pin=bl+br, w=100%, z=5}

### 安全品质：C-NCAP五星标准
- 车身高强度钢占比超80%，热成型钢用量137kg
- CTB电池车身一体化技术，电池安全与车身刚性双重保障
- 7安全气囊、主动刹车、车道保持等全维度主被动安全配置

## 产品节奏
### 2024年3月：SU7正式上市
- 首发标准版/Pro版/Max版三款车型，售价21.59万-29.99万元
- 上市27分钟大定破5万台，引爆新能源轿车市场

### 2024-2025年：产能爬坡与口碑沉淀
- 北京工厂产能持续爬坡，月交付量稳步提升
- 用户口碑验证：设计、性能、智能三大核心优势获市场认可

### 2025年起：产品矩阵持续扩展
- SU7 Ultra性能版推出，进一步拉高品牌上限
- 后续SUV车型规划，覆盖更广泛的用户群体

## 长期愿景

用小米的技术积累和生态优势，成为全球领先的智能电动汽车品牌
- 短期：让SU7成为20-30万级纯电轿车的标杆产品
- 中期：完成轿车+SUV的产品矩阵布局，年销量冲击30万辆
- 长期："人车家全生态"闭环，让汽车成为小米生态的核心智能终端
